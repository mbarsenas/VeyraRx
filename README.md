# SmarteRX Web Prototype

Security controls, verification evidence, operational requirements, and the remaining hardening backlog are maintained in [`docs/SECURITY-HARDENING.md`](docs/SECURITY-HARDENING.md).

Original Next.js concept inspired by modern pharmacy-benefit websites.

## Run

```powershell
npm install
npm run dev
```

Open http://localhost:3000

## Pages

- /
- /pricing
- /pharmacies
- /coverage
- /resources
- /contact
- /orders
- /signin

This is a UI prototype only. No PHI, authentication, claims, pharmacy-network, or live drug-pricing integrations are implemented.
